# Sistema de Gestión de Productos y Pedidos

Programa de consola en C++ para administrar productos y pedidos usando
estructuras de datos implementadas a mano.

## Estructuras de datos
| Estructura | Uso |
|---|---|
| Arreglo dinámico | Almacenamiento principal de productos |
| Cola (FIFO) | Pedidos pendientes |
| Lista enlazada | Pedidos procesados (entregados) |
| Pila (LIFO) | Historial de operaciones |
| Árbol binario de búsqueda | Productos ordenados por código |

## Algoritmos
- **Ordenamiento:** QuickSort (por código, nombre o precio)
- **Búsqueda:** secuencial y binaria
